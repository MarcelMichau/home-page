# Home Page

Marcel Michau's personal portfolio presents profile information, links, and a different palette for each local weekday.

## Language

**Weekday theme**:
One of seven page palettes selected by the visitor's local weekday, with Monday as the default.
_Avoid_: User-selected theme

**Verified site**:
The complete site whose browser checks have passed and which is ready to publish unchanged.
_Avoid_: Untested rebuild
